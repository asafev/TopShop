Signal Methodology

Each signal below attempts a distinct detection vector. Signals marked with high weight (W) are strong Atlas indicators. Signals with low weight may trigger on other automation frameworks too.

1. console.log Override (MVP, W:95)

Atlas replaces console.log with a wrapper containing "captureLogArguments". We call console.log.toString() and search for this substring plus "NodeList.forEach". Both must be present for a hit.

2. window.ChatGPTBrowser (W:90)

Atlas sets window.ChatGPTBrowser as a global marker. Simple property existence check via 'ChatGPTBrowser' in window.

3. navigator.userAgentData Brands (W:80)

Calls navigator.userAgentData.getHighEntropyValues(['brands','fullVersionList']) and checks if any brand name contains "chatgpt", "openai", or "atlas".

4. User-Agent String (W:70)

Checks navigator.userAgent for "ChatGPT-User" or "OAI-SearchBot" substrings. The official ChatGPT-User UA is: Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko); compatible; ChatGPT-User/1.0; +https://openai.com/bot

5. console.debug/warn/error Override (W:75)

If Atlas hooks console.log, it likely hooks other console methods too. We check .toString() of debug, warn, error, info for non-native signatures.

6. navigator.webdriver (W:60)

CDP-controlled browsers often set navigator.webdriver = true. Atlas may or may not patch this out. We check both the property and its descriptor.

7. navigator.plugins Empty (W:40)

Normal Chrome on Mac has plugins (PDF Viewer, etc). Headless/automated Chrome often has an empty navigator.plugins array. We check navigator.plugins.length === 0.

8. Platform: MacIntel Only (W:30)

Atlas runs only on Mac. If navigator.platform !== 'MacIntel', this is definitely NOT Atlas. If it IS MacIntel, it's a necessary (but not sufficient) condition.

9. Window Dimension Anomaly (W:45)

Automated browsers often have outerWidth === innerWidth and outerHeight === innerHeight (no browser chrome). Normal browsers have toolbar/address bar overhead.

10. Permissions API State (W:50)

Queries navigator.permissions.query({name:'notifications'}). Automated browsers often show "denied" or "prompt" without ever having been asked. We also check clipboard-write and camera.

11. chrome.app / chrome.runtime (W:35)

Normal Chrome exposes window.chrome.app (deprecated but present). Automated Chromium may lack this. We check the chrome object structure.

12. Error Stack Trace Paths (W:65)

Throws an intentional error and inspects the stack trace for internal OpenAI paths, sandboxing, or unusual script origins (e.g., "oai", "chatgpt", "atlas" in paths).

13. Performance.getEntries (W:55)

Checks performance.getEntriesByType('resource') for any resources loaded from openai.com, chatgpt.com, or atlas-related domains.

14. speechSynthesis Voices (W:35)

Mac Chrome has system voices (Alex, Samantha, etc). If speechSynthesis.getVoices() returns zero voices, likely headless. If Mac voices present, confirms Mac environment.

15. DevicePixelRatio (W:25)

Mac Retina displays have window.devicePixelRatio === 2. Non-Retina or headless may show 1. Informational signal only.

16. WebGL Renderer (W:30)

Reads UNMASKED_RENDERER_WEBGL from WebGL context. Atlas may show a specific GPU (Apple M1/M2/M3) or "SwiftShader" (headless). Reports the value for comparison.

17. Connection RTT (W:40)

Checks navigator.connection.rtt. Datacenter connections often show 0 or very low RTT. A value of 0 suggests the browser is running in a cloud environment.

18. document.hasFocus (W:30)

Automated browsers often don't have focus. We check document.hasFocus() at scan time. A false value suggests non-interactive context.

19. Notification Constructor (W:45)

Attempts new Notification('test') in a try-catch. Some automated browsers throw or lack the Notification API entirely.

20. Function.prototype.toString Integrity (W:50)

Checks if Function.prototype.toString itself has been tampered with by verifying its own toString() output matches "function toString() { [native code] }".
