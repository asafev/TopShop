Before You Start
💡
DO NOT start with Playwright/Puppeteer APIs. Start here. Deeply understand the architecture first. You need to know why things work, not just how to call them.
  • Open chrome://version to see your Chrome's exact build info and process details
  • Open chrome://process-internals to see live SiteInstance and process mapping
  • Open Chrome Task Manager (Shift+Esc) to observe real process architecture
  • Bookmark Chromium Code Search — you'll use it constantly
  • Bookmark Chromium Design Documents
