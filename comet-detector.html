How it works

Comet (Perplexity's Chromium fork) injects a content script on every page that declares @font-face rules pointing to frontend-cdn.perplexity.ai. This registers "FKGroteskNeue" in the browser's FontFaceSet. On Windows, the font is also installed system-wide and detectable via canvas measurement.

We exploit three independent vectors: (1) enumerate document.fonts for injected FK Grotesk entries, (2) a strict CSP that traps the blocked font-load attempt, and (3) canvas text-width measurement against fallback baselines.

False positive rate: effectively zero — FK Grotesk Neue is a proprietary Perplexity typeface not available anywhere else.
