Signal Explanations

All signals run client-side. No external requests except the WebRTC candidate gathering (STUN) and the self-fetch timing test. Each signal returns raw data for manual comparison between Chrome and Atlas.

MVP: WebRTC IP Leak

Creates new RTCPeerConnection({iceServers:[{urls:'stun:stun.l.google.com:19302'}]}), creates a data channel, and listens for ICE candidates. Extracts IPs from candidate strings. Datacenter IPs or disabled WebRTC both indicate automation.

1. CDP Runtime Domain Detection

CDP injects a binding via Runtime.addBinding. We enumerate window own properties looking for unusual callable bindings (non-standard function properties on window that aren't in a normal Chrome profile).

2. Iframe contentWindow Consistency

Creates a same-origin iframe and compares navigator.userAgent, navigator.plugins.length, and window.chrome between parent and iframe. CDP-controlled browsers sometimes have inconsistencies.

3. setTimeout Precision Timing

Measures actual resolution of setTimeout(fn, 0) over 20 iterations. Normal browsers: 1-4ms. Automated browsers running under load or in VMs: may show different clustering patterns.

4. performance.now() Precision

Samples performance.now() 100 times in a tight loop and checks the minimum delta between consecutive calls. Chrome normally gives ~5us precision. Reduced precision indicates privacy sandbox or automation context.

5. requestAnimationFrame Timing

Runs 10 rAF frames and measures inter-frame timing. Normal: ~16.6ms (60fps). Automated: may be exactly 16.6ms (mocked), 0ms (instant), or highly irregular.

6. alert/confirm/prompt Behavior

Overrides window.alert with a timing wrapper, then calls it. Atlas likely auto-dismisses dialogs. We measure if the call returns instantly (< 1ms) vs blocks (normal browser waits for user).

7. history.length

Fresh automated sessions start with history.length === 1 (or 2 after navigation). A value of 1 on a page that should be navigated-to is suspicious.

8. Proxy/Reflect Trap Detection

Tests if navigator is wrapped in a Proxy by using Object.getPrototypeOf, checking Symbol.toStringTag, and comparing prototype chain depth.

9. screen.width x screen.height

Reports raw screen dimensions. Atlas likely runs in a fixed viewport. Values like 1920x1080 on Mac (where Retina is standard) are suspicious.

10. Web Audio Fingerprint

Creates an OfflineAudioContext, runs an oscillator through a compressor, and hashes the output buffer. Different environments produce different audio fingerprints.

11. Canvas Pixel Extraction

Draws specific text and shapes on a canvas and extracts pixel data hash. Compares with known Atlas rendering (if available). Reports raw hash for comparison.

12. window.opener / window.parent

Checks window.opener, window.parent !== window, and window.frameElement. Atlas may run pages in a controlled frame structure.

13. document.visibilityState

Checks if the page is visible or hidden. Automated browsers may report hidden or prerender state.

14. navigator.languages Full Array

Reports the full navigator.languages array. Automated browsers often have only ["en-US"] vs real users who have regional preferences.

15. Timezone vs IP Location

Gets Intl.DateTimeFormat().resolvedOptions().timeZone. If Atlas runs from US datacenters, timezone should be US-based. A mismatch between timezone and what we expect from an OpenAI server is informational.

16. Error.captureStackTrace

Tests Error.captureStackTrace and Error.stackTraceLimit. CDP-injected scripts may alter these. Also checks if Error stack formatting matches V8 standard.

17. Blob URL / createObjectURL

Creates a Blob URL worker and checks if it can communicate back. Some sandboxed automation contexts restrict Blob URL creation or Worker spawning.

18. SharedArrayBuffer Availability

Tests if SharedArrayBuffer is available. Requires cross-origin isolation headers (COOP/COEP). Atlas may or may not have these headers.

19. Installed Fonts via Canvas

Measures text width for strings rendered in 50 common Mac fonts. Atlas may have a stripped-down font set compared to a real Mac with user-installed fonts.

20. navigator.hardwareConcurrency

Reports CPU core count. Cloud VMs often have specific core counts (2, 4, 8). Unusual values or very high counts may indicate datacenter hardware.

21. navigator.deviceMemory

Reports device memory in GB. Cloud VMs may report unusual values. Normal Macs: 8, 16, 32, 64.

22. Self-Fetch Response Timing

Fetches the current page URL and measures response time. If running locally, it should be < 50ms. If Atlas proxies through OpenAI infrastructure, latency will be higher.

23. Mouse/Keyboard Event Listener Test

Registers event listeners and reports if any synthetic events fire within 2 seconds. Atlas's AI cannot produce real mouse/keyboard events with proper isTrusted flag.

24. window Property Enumeration

Counts own properties on window and looks for non-standard ones. CDP and automation inject properties like cdc_, custom bindings, or OpenAI-specific globals.
